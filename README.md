# SEU 素质讲座抢座助手

东南大学「素质讲座」(jzxxtjapp)自动预约工具:输入统一认证账号密码即可登录,自动查询讲座列表、校准服务器时间、到点自动抢座(自动获取并识别图形验证码),全自动完成预约。

> ⚠️ 本项目仅供学习交流与个人使用,请合理使用、勿高频请求,抢到后请按时参加讲座。

## 功能特性

- **账号密码直接登录**:无需打开浏览器,复刻统一认证(`auth.seu.edu.cn`)完整协议:RSA 公钥获取 → 密码加密 → CAS 登录 → 门户/应用双层会话建立
- **讲座列表实时查询**:名称、容量、已约人数、**预约开放时刻倒计时**
- **服务器时间校准**:通过 HTTP `Date` 头测量本机与服务器时钟差(实测本机慢约 4 分钟),开始时间自动换算,到点精准开抢
- **自动验证码**:自动获取图形验证码 → ddddocr 限定数字字符集识别 → 严格 4 位纯数字规则校验 → 不合格自动换图重试
- **五层容错**:事前校验 / 判错秒级重试 / 连续失败自动降级手动模式 / 环境降级 / 循环兜底
- **会话持久化**:Cookie 每次调用后自动存盘,重启免登录;会话被顶(401)自动识别并提示
- **Web 操作界面**:本地网页操作,实时日志、验证码展示、任务状态一目了然

## 环境要求

- Windows + Python 3.10+
- 依赖见 `requirements.txt`(FastAPI / Playwright / ddddocr 等)

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python -m uvicorn app:app --host 127.0.0.1 --port 8787
```

或者 Windows 下直接双击 `start.bat`(自动检测依赖、首次自动安装、自动打开浏览器)。

打开 `http://127.0.0.1:8787`:

1. **① 登录**:输入一卡通号 + 统一认证密码
2. **② 讲座列表**:点选想抢的讲座
3. **③ 抢座配置**:开始时间已自动换算为本机时间,验证码模式默认自动 OCR
4. **启动抢座**:任务倒计时,到点自动执行

## 工作原理(协议逆向)

```
登录链路(两段式):
  统一认证段:getChiperKey 拿 RSA 公钥(定制 base64,-/+、_// 等价)
              → casLogin 提交(密码 RSA PKCS#1 v1.5 加密)→ 获取 TGT
  应用会话段:appShow 签发带 gid_ 授权参数的应用入口
              → verifyTgt 用 TGT 换绑定应用 service 的 ST ticket
              → 带 ticket 逐跳访问应用入口 → 签发 GS_SESSIONID / _WEU

抢座链路:
  queryActivityList.do   讲座列表(WID / 容量 / 开放时间)
  vcode.do               获取 4 位数字图形验证码(base64)
  appiontCheck.do        预约前置校验
  yySave.do              提交预约 paramJson={HD_WID, vcode}
```

关键细节:ST ticket 与 service 绑定(门户 ticket 进不了应用)、`_WEU` Cookie 每次响应滚动更新、导航类请求不能携带 `X-Requested-With` 头(否则被后端判为 AJAX 直接 401)。

## 常见问题

- **登录失败/会话失效**:重新登录一次即可(会话有过期时间)
- **自动 OCR 总失败**:切到"手动输入"模式,到点后页面输入 4 位验证码
- **浏览器没自动打开**:手动访问 `http://127.0.0.1:8787`
- **开代理抓包软件**(Fiddler/Reqable 等):工具已自动直连,不受影响
