# SEU 素质讲座抢座助手

东南大学「素质讲座」(jzxxtjapp)自动预约工具:输入统一认证账号密码即可登录,自动查询讲座列表、校准服务器时间、到点自动抢座(自动获取并识别图形验证码),全自动完成预约。

> ⚠️ 本项目仅供学习交流与个人使用,请合理使用、勿高频请求,抢到后请按时参加讲座。

## 环境要求

- Windows + Python 3.10+
- 依赖见 `requirements.txt`(FastAPI / Playwright / ddddocr 等)

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python -m uvicorn app:app --host 127.0.0.1 --port 8787
```

或者 Windows 下直接双击 `start.bat`(自动检测依赖、首次自动安装、自动打开浏览器)。

打开 `http://127.0.0.1:8787`:

1. **① 登录**:输入一卡通号 + 统一认证密码
2. **② 讲座列表**:点选想抢的讲座
3. **③ 抢座配置**:开始时间已自动换算为本机时间,验证码模式默认自动 OCR
4. **启动抢座**:任务倒计时,到点自动执行

## 项目结构

```
├── app.py            # FastAPI 后端:登录/会话/讲座/定时抢座任务
├── static/index.html # Web 操作界面
├── requirements.txt  # 依赖
├── start.bat         # Windows 一键启动
└── 使用说明.txt       # 详细使用说明
```

## 常见问题

- **登录失败/会话失效**:重新登录一次即可(会话有过期时间)
- **自动 OCR 总失败**:切到"手动输入"模式,到点后页面输入 4 位验证码
- **浏览器没自动打开**:手动访问 `http://127.0.0.1:8787`
- **开代理抓包软件**(Fiddler/Reqable 等):工具已自动直连,不受影响
